# 排行榜海报编辑器设计

## 目标

在现有站点最上层的两个并列工具入口之外，新增第三个同级入口“排行榜海报”。该页面用于把已经整理好的榜单数据做成最终海报：补视觉图、调整裁切、微调字体与排版、实时预览并导出透明 PNG。

第一版不解析原始问卷 Excel，也不负责重新计算问卷数据或抓取 Bangumi；它只消费整理后的榜单数据。原始问卷文件继续留在仓库外。

## 与现有站点的关系

“排行榜海报”与现有“题目文本导出”和“YUC 图卡导出”并列，不作为问卷页内部的题型、平台或二级选项。

现有站点继续保持纯前端、本地图片不上传服务器的原则。排行榜编辑器也在浏览器本地完成图片导入、裁切状态、字体加载、预览和 PNG 导出。

## 渲染方案

浏览器端使用 Canvas 重现当前 Pillow 原型的固定几何和视觉规则。Pillow 版本保留作为参考实现和离线输出工具，但网页编辑器不依赖 Python 服务。

Canvas 基础画布仍为 1200×1800，透明背景；排名区、视觉图区、评分区、趋势箭头、趋势色带、标题排版等沿用当前已确认的海报规则。

## 页面结构

页面采用“编辑区 + 实时预览”布局。

编辑区包含三组内容：

1. 榜单内容
   - 红榜 / 黑榜模式。
   - 最多 10 个条目。
   - 每项可编辑标题、社内平均分、投票数、 Bangumi 分数。
   - 同分排序规则继续由现有逻辑保证。
   - 支持单条标题人工换行覆盖，例如 Re0；不改变普通条目的自动换行规则。

2. 视觉图
   - 每项可从本地选择图片。
   - 图片只保留在当前浏览器会话。
   - 每项提供“调整裁切”。
   - 裁切不修改原图，而保存 `scale`、`offsetX`、`offsetY` 等参数。
   - 裁切视窗直接使用最终视觉图 699×136 的比例。
   - 支持拖动平移；支持滑杆或滚轮缩放；可恢复默认居中 cover。
   - 点击海报预览中的某一行时，左侧自动选中对应条目。

3. 样式
   - 可分别调整主标题、副标题、动画标题、排名数字、平均分、差值、辅助文字所用字体。
   - 可调整这些角色的字号。
   - 可调整主副标题行距。
   - 可调整负号纵向光学校正值。
   - 第一版不开放全部几何坐标和全部颜色，避免把工具变成通用绘图软件。

## 字体

提供两种方式：

- 输入/选择常见字体族名称；
- 从本地加载 `.ttf` / `.otf` / 浏览器可接受的字体文件，通过 `FontFace` 临时注册。

本地字体只进入当前浏览器内存，不上传、不提交仓库。

## 数据流

整理后的榜单 JSON → 排行榜编辑器 → 补视觉图并调整裁切 → 调整字体/字号/间距 → Canvas 实时预览 → 导出透明 PNG。

第一版同时支持下载“海报项目 JSON”。项目文件保存：

- 榜单数据；
- 红榜/黑榜模式与阈值；
- 样式参数；
- 每项图片文件名；
- 每项裁切参数；
- 人工标题换行覆盖。

第一版项目 JSON 不内嵌图片二进制。重新打开项目时，如果图片缺失，提示用户重新选择对应本地图片。

## 预览与导出

- 页面内持续显示缩放后的完整 1200×1800 海报预览。
- 修改文字、样式或裁切参数后立即重绘。
- 导出使用 Canvas 原始 1200×1800 分辨率，不按预览缩放尺寸导出。
- 输出 PNG 保持透明背景。

## 与当前 Python 原型的关系

当前 `tools/ranking-poster/render.py` 中已经确认的几何、排序、趋势阈值、箭头素材和排版规则是浏览器 Canvas 实现的基线。

前端实现尽量共享同一份可读配置数据，而不是复制一套彼此无法核对的魔法数字。Python 版不删除，继续用于对照网页输出和批量离线渲染。

## 第一版明确不做

- 不解析或上传原始 Excel 问卷。
- 不在网页内自动抓 Bangumi API。
- 不上传用户图片或字体到服务器。
- 不实现自由旋转、滤镜、任意图层等通用图片编辑能力。
- 不把视觉图片二进制嵌入项目 JSON。

## 完成标准

1. 顶层出现第三个“排行榜海报”入口，与现有两个工具同级。
2. 能载入整理好的榜单数据并画出与当前 Pillow 原型结构一致的海报。
3. 十个条目都能分别导入本地视觉图并在 699×136 视窗中拖动、缩放裁切。
4. 能在前端修改主要字体、字号、标题行距和负号偏移，并实时看到效果。
5. 能从完整 Canvas 导出透明 1200×1800 PNG。
6. 能下载/重新载入不含图片二进制的海报项目 JSON。
7. 原始问卷数据不进入仓库，用户图片和字体不上传网络。

# Bangumi Easy Vote

这个仓库用于逐步验证和实现新番投票准备工作的自动化。目前已经完成三块可以独立检查的成果：

1. 从 YUC 新番表取得视觉图，并由 Chromium 原样导出放送小卡和横向资料卡。
2. 在问卷星、腾讯问卷的真实文本导入编辑器中测试题型、空行和不可见字符的解析结果。
3. 用本地工作台批量整理动画标题或视觉图，并生成两个平台的导入文本。

## 本地动画投票工作台

工作台不需要安装第三方依赖。电脑上有 Node.js 20 或更新版本时，在仓库目录运行：

```text
npm run dev
```

然后打开 `http://127.0.0.1:4173/`。页面会在本地读取所选图片，不会把图片上传到任何服务器。

### 基本用法

1. 填写问卷标题和说明。
2. 在“批量粘贴标题”中每行放一部动画，点击“加入标题”；或者点击“选择多张图片”。
3. 图片文件名去掉最后一个扩展名后会成为初始标题，可继续改名、排序或删除。
4. 选择问卷星或腾讯问卷，再选择季度最期待、逐部评分或追番状态。
5. 检查右侧诊断和生成文本，然后复制文本，或下载 TXT。
6. 如需保留图片文件名与题目顺序，可下载项目 JSON。

### 题目范式映射

| 范式 | 问卷星 | 腾讯问卷 |
| --- | --- | --- |
| 季度最期待 | 一道单选题 | 一道单选题 |
| 逐部评分 | 一道矩阵题 | 每部动画一道量表题 |
| 追番状态 | 一道矩阵题 | 每部动画一道下拉题 |

腾讯问卷的矩阵文本标签在真实编辑器中解析失败，因此工具不会猜测该语法，而是展开为已经验证过的题型。

### 自动清理

生成器会移除零宽字符、BOM、不换行空格和行尾空白，并避免在选择题内部插入空行。自动测试覆盖两个平台的六种组合：

```text
npm test
```

设计边界见 [`动画投票生成器设计说明`](docs/superpowers/specs/2026-08-23-anime-vote-generator-design.md)，分阶段实施记录见 [`实施计划`](docs/superpowers/plans/2026-08-23-anime-vote-generator.md)。

## 当前验证结果

- 页面从 `http://yuc.wiki/202607/` 读取，不强制使用 HTTPS。
- 原始视觉图可直接保存，本例为 600×750。
- 放送小卡可按网页原尺寸导出，也可让 Chromium 以 5 倍设备像素密度重新渲染为 600px 宽的清晰版本。
- 横向资料卡按“左侧视觉图 + 右侧固定宽度资料表”的真实边界导出，不包含会自动撑满页面的外层空白。
- 高清卡片中的文字、颜色和排版均由 Chromium 按原网页样式渲染，没有使用 Python 绘字或替换字体。

## 表单文本导入实测

实测结果、安全模板和生成前清洗规则见 [`form-import-findings.md`](form-import-findings.md)。测试只使用左右分栏的实时预览，没有点击问卷星“完成”或腾讯问卷“发布”，测试结束后两个编辑器均已恢复原始示例。

## 当前限制

- 文本导入不会自动把图片上传到问卷星或腾讯问卷。
- 工具不会登录平台、点击完成或发布问卷。
- 刷新页面会清空当前编辑内容；需要留档时先下载项目 JSON。
- 项目 JSON 保存图片文件名和题目顺序，不保存只在当前页面有效的本地图片地址。
- 首版只提供三种动画投票范式，不是任意题型的通用问卷设计器。

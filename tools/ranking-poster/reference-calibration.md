# Anime Corner 榜单参考图校准

这个目录中的长图原型不是“做一个相似风格”，而是按参考图的固定几何结构复刻。现阶段仍不接入现有投票 HTML。

## 参考图尺寸

两张参考图均为 **1200 × 1800 px**。

## 2026 参考图的实测骨架

### 页头

- 页头底部：`y = 145`，主体背景从 `y = 146` 开始。
- 左侧品牌色块右边界：`x = 343`，因此宽度约 `344 px`。
- 右侧为黑底标题区。

### 榜单横向分栏

从普通榜单行的稳定色块边界得到：

- 整行左边界：`x = 22`
- 名次块：`x = 22..131`，宽 `110 px`
- 视觉图：`x = 132..830`，宽 `699 px`
- 数据区：`x = 831..1175`，宽 `345 px`

这三段合计 `1154 px`。

### 榜单纵向位置

参考图中的十行并不是一个恰好整数间距的 CSS Grid；行间隔约在 13/14 px 间交替。为了避免到第十行累计产生 4–5 px 漂移，原型直接记录实测行起点：

```text
168, 317, 467, 616, 766,
915, 1065, 1214, 1364, 1514
```

单行高度按 `136 px` 处理。第十行结束在约 `y = 1649`，页脚从 `y = 1650` 开始。

### 右侧数据区

原图的 `RANK PROGRESSION / VOTE PERCENTAGE` 顶部标签 **只出现一次**，位于第一行上方，而不是每一行重复。

本项目保留这个结构，但改为：

- `AVERAGE SCORE`
- `RATERS`

每一行内部则显示两项大数字，并在底部用细条重复简短说明。

### 视觉图区

参考图并非简单把截图原样塞进去：

1. 固定窗口裁切；
2. 左侧和下侧加暗幕，确保白色标题可读；
3. 标题贴近左下；
4. 行之间有很薄的阴影/悬浮感。

我们的素材改用横版视觉图，仍保留 `focus` 参数控制裁切焦点，避免机械居中裁掉人物。

## 颜色采样

2026 参考图中可以稳定采到：

- 前三名：`#FF686F`
- 4–10 名：`#EF9448`
- 主体青色：`#6AD2D6`
- 数据区：`#1E1E1E`
- 页脚：`#FFE9CC`
- 黄色底条：`#FFB018`
- 绿色底条：约 `#36C120`

## 字体

当前只校准字重、字号与占位，不在仓库中携带字体文件。西文主标题需要极粗几何无衬线；中文动画名使用粗黑体。Pillow 脚本支持通过环境变量指定本机字体路径，后面再继续对字形本身做比对。

# Anime Corner 榜单参考图校准

这个目录中的长图原型不是“做一个相似风格”，而是按参考图的固定几何结构复刻。现阶段仍不接入现有投票 HTML。

## 参考图尺寸

两张参考图均为 **1200 × 1800 px**。

## 2026 参考图的实测骨架

### 页头

- 页头底部：`y = 145`，主体背景从 `y = 146` 开始。
- 左侧品牌色块右边界：`x = 343`，因此宽度约 `344 px`。
- 右侧为黑底标题区。

### 榜单横向分栏

从普通榜单行的稳定色块边界得到：

- 整行左边界：`x = 22`
- 名次块：`x = 22..131`，宽 `110 px`
- 视觉图：`x = 132..830`，宽 `699 px`
- 数据区：`x = 831..1175`，宽 `345 px`

这三段合计 `1154 px`。

### 榜单纵向位置

参考图中的十行并不是一个恰好整数间距的 CSS Grid；行间隔约在 13/14 px 间交替。为了避免到第十行累计产生 4–5 px 漂移，原型直接记录实测行起点：

```text
168, 317, 467, 616, 766,
915, 1065, 1214, 1364, 1514
```

单行高度按 `136 px` 处理。第十行结束在约 `y = 1649`，页脚从 `y = 1650` 开始。

## 已确认的右侧数据区设计

原图的 `RANK PROGRESSION / VOTE PERCENTAGE` 顶部标签只出现一次，位于第一行上方，而不是每一行重复。本项目继续保留这个结构，但右侧栏的最终信息层级改为“社内平均分 vs Bangumi 比较”，评分人数降为次级信息。

单行右栏按下面的结构设计：

```text
┌───────────────────┬──────────────────┐
│  AVERAGE SCORE    │ 和 Bangumi 比较  │
├───────────────────┼──────────────────┤
│       8.57        │     ↑↑ +1.63     │
├──────────────────────────────────────┤
│   投票数 7                         BGM 6.94
└──────────────────────────────────────┘
```

其中：

- 左上标题固定为 `AVERAGE SCORE`。
- 右上标题表达“与 Bangumi 比较”，**具体英文/中文文案暂未最终确定**；例如 `VS BANGUMI` 可以作为候选，但实现时不要把当前候选写死成不可调整的设计决定。
- 中间左侧用大字显示社内平均分，例如 `8.57`。
- 中间右侧用“大趋势箭头 + 差值”作为与平均分同级的主视觉，例如 `↑↑ +1.63`。
- 评分人数不再占据一个主数据大格；它只在最下方辅助栏左侧显示，例如 `投票数 7`。
- Bangumi 原始评分放在最下方辅助栏右侧，例如 `BGM 6.94`。
- 最下方辅助栏需要比当前 20–22 px 的细条**明显加高**，使 `投票数` 与 `BGM` 能正常阅读，但仍保持为次级信息。具体高度在实际出图时继续视觉校准，不在这里过早写死。
- 最下方应被理解为一整条统一的辅助信息区，而不是两个互相抢视觉权重的主指标格。

### 趋势箭头必须单独绘制

趋势箭头不是字体字符，也不要直接用 Unicode 的 `↑`、`↓`、`↔` 代替最终图形。应按参考图的视觉语言用 Pillow/SVG 几何绘制为独立组件。

要求：

- 箭头的视觉尺寸明显大于旁边的差值文字，先让观众看到方向，再读具体差值。
- 上升：两根平行向上的绿色箭头。
- 下降：两根平行向下的红色箭头。
- 持平：两根错开、方向相反的黄/橙色横向箭头，参考原图的 `→ / ←` 组合，而不是一个普通 `↔` 字符。
- 箭头图形与 `+1.63` / `-1.20` 等差值是两个独立视觉对象，在比较栏中组成一组。
- 箭头承担主要颜色编码后，不需要再依赖底部整块高饱和色来表达 up / flat / down。

### 顶部标签必须完整显示

`AVERAGE SCORE` 和右侧比较标题必须完整显示，不得再出现被第一行覆盖、文字框过窄或只能显示一部分的问题。顶部标签应完整占据第一行上方的空间，并在绘制顺序上位于榜单行之上。

## 红榜 / 黑榜的数据规则

当前已确认的排序规则：

- 红榜：社内平均分降序；平均分相同时，评分人数更多者优先。
- 黑榜：社内平均分升序；平均分相同时，评分人数更多者优先。

Bangumi 比较使用原始 Bangumi 分数，不做 `+1`、归一化或标准差校正。红榜与黑榜使用不同的分段基线，以抵消“红榜天然偏高、黑榜天然偏低”的直观尺度差异。

当前暂定阈值：

- 红榜：`社内 - BGM >= +1.0` 为上升；`+0.4 <= 差值 < +1.0` 为持平；`差值 < +0.4` 为下降。
- 黑榜：`社内 - BGM > -0.4` 为上升；`-1.0 < 差值 <= -0.4` 为持平；`差值 <= -1.0` 为下降。

这些阈值作为当前海报规则保留为可配置参数，不应散落硬编码在绘图逻辑各处。

## Bangumi 分数数据要求

- 海报中显示 Bangumi 分数时建议保留两位小数。
- 比较和箭头判断使用未舍入的精确均分。
- 若能取得 1–10 分各档人数，应以评分直方图重新计算加权平均，而不是依赖页面只显示一位小数的 `score`。
- 使用评分直方图时必须做一致性检查：十档人数求和与当前评分数应基本一致；按十档重算的均分四舍五入到页面显示精度后，应与页面显示分数一致。
- 若不同组件来自不同缓存时点而无法通过一致性检查，该条数据不能直接进入最终海报，应重新获取。

## 视觉图区

参考图并非简单把截图原样塞进去：

1. 固定窗口裁切；
2. 左侧和下侧加暗幕，确保白色标题可读；
3. 标题贴近左下；
4. 行之间有很薄的阴影/悬浮感。

我们的素材改用横版视觉图，仍保留 `focus` 参数控制裁切焦点，避免机械居中裁掉人物。

## 透明背景

最终 PNG 保持 RGBA。除页头、排名块、视觉图、数据区等实际组件外，画布底层与页脚背景均使用透明像素，后续背景由外部排版自行叠加。

## 颜色采样

2026 参考图中可以稳定采到：

- 前三名：`#FF686F`
- 4–10 名：`#EF9448`
- 主体青色（仅作为参考图采样，不再作为最终画布底色）：`#6AD2D6`
- 数据区：`#1E1E1E`
- 页脚原参考色：`#FFE9CC`
- 黄色：`#FFB018`
- 绿色：约 `#36C120`

## 字体

字体文件不随仓库提交。字体选择必须保持可配置；页头、动画标题、排名数字、主数据、辅助文字等角色允许分别覆盖。

当前原则：

- 西文主标题使用极粗几何无衬线风格。
- 中文动画名使用粗黑体方向。
- 页头主标题必须有可靠的 CJK 回退，不能再出现汉字缺字/方框。
- 字体本身仍属于后续视觉校准项，当前代码结构不要把某一款字体固化为不可替换依赖。
